# Éder Venâncio | Portfólio Técnico

Profissional de Tecnologia da Informação com experiência em sistemas empresariais, análise de dados, integração de sistemas e infraestrutura de TI.

Este repositório reúne exemplos demonstrativos de código voltados à resolução de problemas técnicos e de negócio, utilizando SQL Server, Python, APIs REST e ADVPL no contexto de sistemas empresariais.

## Tecnologias

- **Banco de dados:** SQL Server, SQL, consultas e agregações
- **Integração:** Python, APIs REST e JSON
- **ERP:** TOTVS Protheus e ADVPL
- **Infraestrutura:** Redes, serviços corporativos e ambientes empresariais
