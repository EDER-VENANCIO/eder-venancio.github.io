def consultar_usuario(usuario_id: int) -> dict | None:
    url = f"https://jsonplaceholder.typicode.com/users/{usuario_id}"
    requisicao = Request(url, headers={"Accept": "application/json"})
    with urlopen(requisicao, timeout=10) as resposta:
        return json.loads(resposta.read().decode("utf-8"))

PROJETO 03

Auditoria de cálculo fiscal com SQL

Construção de consulta para cruzar dados fiscais do ERP, recalcular valores de ICMS-ST em um cenário definido e comparar o resultado com os valores registrados. Parâmetros fixos foram usados na validação da fórmula antes da conferência com os campos do sistema.

SQL ServerProtheusAuditoriaICMS-ST
Ver trecho de código SQL
SELECT
    FT.FT_FILIAL AS 'FILIAL',
    FT.FT_CFOP AS 'CFOP',
    FT.FT_NFISCAL AS 'NOTA',
    ROUND(
        FT.FT_OUTRICM * (63.87 / 100.0) + FT.FT_OUTRICM,
        2
    ) AS 'BC_ICMS_ST_CORRETA'
FROM SFT010 AS FT
WHERE FT.D_E_L_E_T_ = ' ';

Consulta demonstrativa com cruzamento de tabelas fiscais, parâmetros e cálculos de conferência.

PROJETO 04

Análise de estoque e custos

Consulta para consolidar quantidade e valor estimado de estoque por filial e produto. O exemplo demonstra agregações SQL e cálculo de valores, com necessidade de validação conforme as regras de custo e estoque do ambiente.

SQL ServerProtheusEstoqueAgregações
Ver trecho de código SQL
SELECT
    B2_FILIAL AS FILIAL,
    B2_COD AS PRODUTO,
    SUM(B2_QATU) AS QUANTIDADE_ESTOQUE,
    SUM(B2_QATU * B2_CM1) AS VALOR_ESTIMADO_ESTOQUE
FROM SB2010
WHERE D_E_L_E_T_ = ''
GROUP BY B2_FILIAL, B2_COD;

Demonstra consolidação por filial e produto e cálculo de valor estimado de estoque.
