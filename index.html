Projetos em destaque

Projetos e soluções aplicadas a desafios reais de sistemas empresariais, dados, processos fiscais, integrações e infraestrutura. Os exemplos foram descritos de forma genérica para preservar informações internas.

PROJETO 01

Infraestrutura e segmentação de rede

Participação na evolução da rede corporativa com switches gerenciáveis, pontos de acesso Wi-Fi e administração centralizada. Organização da infraestrutura e segmentação lógica por perfis de uso para melhorar o controle e a segurança do ambiente.

Redes VLAN Fortinet UniFi
PROJETO 02

Integração ERP com CRM via API

Desenvolvimento de consultas SQL para extração de cadastros do ERP e rotinas em Python para envio de dados a uma API REST. Trabalho com mapeamento de campos, chaves, relacionamentos entre entidades e validação dos dados após a carga.

SQL Server Python API REST Integração
PROJETO 03

Auditoria de cálculo fiscal com SQL

Construção de consulta para cruzar dados fiscais do ERP, recalcular valores de ICMS-ST em um cenário definido e comparar o resultado com os valores registrados. Parâmetros fixos foram usados na validação da fórmula antes da conferência com os campos do sistema.

SQL Server Protheus Auditoria ICMS-ST
PROJETO 04

Diagnóstico de retenções tributárias

Consulta de diagnóstico para cruzar notas de saída, pedidos, natureza financeira, TES, produto e cadastro de cliente. A análise destaca indicadores de configuração relacionados a IRRF, PIS, COFINS e CSLL, apoiando a equipe fiscal na investigação de casos sem retenção.

SQL Protheus Fiscal Diagnóstico
PROJETO 05

Adequação de exportação DEF com ADVPL

Criação de rotina complementar para gerar arquivo CSV a partir de dados do ERP, com seleção de período e código, consulta via SQL embarcado e aplicação de regras específicas de formatação e correspondência de códigos durante a exportação.

ADVPL SQL embarcado CSV Protheus
PROJETO 06

Implantação do GLPI com LDAP

Implantação do GLPI em servidor Ubuntu e integração com Active Directory via LDAP. Configuração de grupos, perfis de acesso, categorias e encaminhamento de chamados, inventário de ativos, prazos de atendimento e notificações por e-mail.

GLPI Ubuntu Linux LDAP / AD Service Desk
